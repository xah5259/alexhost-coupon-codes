## How to apply an AlexHost coupon at checkout

The order flow is the standard billing-system one, and the field is easy to miss because it sits below the account and payment details.

1. Pick the service and configuration, then start the order.
2. Create an account or log in, and fill in the contact and billing details.

**Renewal discounts take a different path.** A renewal code can't be applied at checkout because there's no order being placed. Two rules apply to everything on this page. AlexHost's FAQ states that coupons and promotions cannot be combined, and that one coupon or promotion covers a single service. If you're ordering a VPS and a dedicated server together, you're applying the code to one of them, so put it on the more expensive one.
